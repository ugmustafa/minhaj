# Минхадж — личный учебный план

Веб-приложение (PWA) для самостоятельной учёбы: очередь книг, нормы, расписание вокруг намазов Медины, учёт и прогнозы.

- Сайт: https://ugmustafa.github.io/minhaj/ (папка `docs/` — готовая сборка)
- Исходники: `src/`, автотесты расчётов: `tests/`
- Сборка: `node build.mjs` (esbuild + sharp), тесты: `node --import tsx --test tests/engine.test.ts`

Данные хранятся на устройстве (IndexedDB). Ключей и токенов в репозитории нет.
